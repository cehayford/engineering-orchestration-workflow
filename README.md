# Engineering Orchestration Workflow

A production-ready engineering orchestration guide for AI-augmented startup development — full-stack, backend, frontend, and AI.

## Contents

- **[`engineering-orchestration-workflow.md`](./engineering-orchestration-workflow.md)** — the Senior Engineer Master Workflow playbook: roles, phases, quality systems, task management, harness engineering, and startup lifecycle guidance.

## Overview

The playbook combines an Agile + V-Model hybrid methodology with five senior engineering roles and a six-phase delivery cycle. It is iterative, modular, AI-augmented, and tool-agnostic — designed to keep production quality high from day one.

## Usage

Open the playbook and apply the methodology to your development workflow. The document includes ready-to-use prompt templates for directing AI assistants (e.g., Claude) as senior engineers.
